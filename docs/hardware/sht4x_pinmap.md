# SHT4x 到 OpenMV4 H743 的接线

MCU 引脚的唯一来源是 [`board_pinmap.md`](board_pinmap.md)。SHT4x 使用 I2C1；它与板载
摄像头 FPC 的 SCCB 网络复用，因此本项目配置下不得连接摄像头。

| SHT4x 模块信号 | STM32H743 端 | 配置/边界 |
|---|---|---|
| SCL | PB8 | I2C1_SCL，AF4，开漏，100 kHz |
| SDA | PB9 | I2C1_SDA，AF4，开漏，100 kHz |
| VCC / VIN | 3V3 | 禁止接 5 V |
| GND | GND | 与所有外设共地 |

新板在 PB8/PB9 到摄像头 FPC 的网络上已有各 4.7 kΩ 上拉至 3.3 V。接入模块前先确认模块
是否自带上拉；通常不再额外并联。驱动继续只探测 `0x44` 与 `0x45`，必须恰好一个地址应答。

上板验收：断电确认摄像头未接与引脚导通；读序列号；用 `0xFD` 做高重复性测量并验证每个
16 位字段的 CRC-8；连续读取 30 分钟。当前没有把 I2C/RTC 硬件启动接入运行时，这一限制
与换板前相同，不能把本接线表视为功能已启用。
