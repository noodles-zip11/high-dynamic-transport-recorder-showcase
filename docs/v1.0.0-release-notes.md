# 高动态运输事件记录器 V1.0.0

V1.0.0 固定了从 ICM45686 采集到自然事件、U2 持久化、UART3/TERP 下载、PySide6 回放、
四分类端侧推理和 Cortex-M7 WFI 的首个完整版本。

## 文档勘误

源仓库中的不可变 tag `v1.0.0^{}` 指向
`a69b6c6c71b91e1267780c169760eca284b7523b`。该 tag 内的根 README 保留了封板验收前的
措辞，仍把 TinyML 写成占位版并把部分门禁写成未完成；这是发布说明陈旧，不代表 tag 内
固件缺少四分类模型或后续实板验收无效。

源仓库标签不会移动或改写；脱敏公开快照没有复制该标签或原 Git 历史。当前能力说明和后续整理的精选证据以
[仓库内的 V1 证据包](../evidence/releases/v1.0.0/)
为准；该后续整理只修正文档和证据入口，不改变 V1 固件、协议或模型字节。

## 已验收能力

- 1.6 kHz ICM45686 FIFO/DMA 采集和 packet-aligned backlog 排空；
- impact/drop 自然触发、one-shot admission、30 s cooldown；
- 固定 EV03：25 pre + 50 post blocks，共 2400 samples；
- U2 SPI2 W25Q64 EL01 事件日志、CRC、重启恢复和 UART3/TERP 下载；
- PySide6 ReplayWidget 回放及离屏 PNG 导出；
- 真实受控数据四分类模型和 MCU 推理/sidecar 链路；
- 固件 OTA、模型 A/B 槽、校验与回滚软件链；
- 普通 Cortex-M7 Sleep/WFI、唤醒归因和 DMA/event/storage/AI/TERP/OTA blocker。

## AI 结果边界

四分类模型使用 91 条合格真实事件，固定 split 为 64/14/13；int8 test 为 10/13，
macro-F1 为 0.755952。`within_session_pilot=true`，因此该结果证明真实 AI 链路可运行，
不证明独立 session 或所有运输场景的泛化准确率。

## 明确未声明

- 没有实测节电百分比、平均电流或 9000 mAh 电池续航；
- STOP/Standby、tickless、IMU Wake-on-Motion 不属于 V1；
- 100 次受控掉电、完整物理断连矩阵和 72 小时长稳属于后续可靠性工作；
- AI 预测不替代逐事件人工真值。
