## 结论

Event 4 可以标为 `background` / `static_baseline`，备注
`manual_trigger;still_baseline;controlled_bench_simulation`。它适合做数据链路和
静态噪声基线检查；正式训练前仍需采集不同日期、不同动作来源和足够数量的独立 session。
