## 单轮操作协议

1. 我先确认本轮编号、区段、断电窗口和日志目录已就绪。
2. 操作者只切断板卡主电源，确认指示灯熄灭后回复“G2 第 N 轮已断电”。
3. 我确认断电记录并通知上电；操作者上电后回复“G2 第 N 轮已上电”。
4. 我用 `scripts/hardware_acceptance_readback.py` 执行 UART3 只读读回并保存结果。
5. 只有机器判定和人工阶段记录都完整，才计入该轮；超时、端口未枚举或阶段不明的轮次不计入 PASS。
