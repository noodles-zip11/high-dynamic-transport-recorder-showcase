# Phase 05 预触发缓存与最小事件闭环设计

## 目标与范围

在不接入 Flash、GUI 或 AI 的前提下，将 ICM45686 的连续 1.6 kHz 六轴数据变成一条可验证、可导出、可回放的单事件证据。事件包含触发前历史、触发后数据和严格校验的 EV01 调试文件。

本阶段不保存多个并发大事件，不判断设备是否损坏，也不实现长事件的 Flash 分段持久化。

## 已确认的资源边界

- 总样本块为 128；每块 64 样本，约 40 ms。
- 采集链路始终保留至少 8 块，不能被环形缓存或事件占用。
- 标准事件为 1 秒预触发加 2 秒后触发。
- 连续触发可延长后触发窗口，但事件窗口最多为 1 秒预触发加 3 秒后触发，即 4 秒总窗口。
- 长于上限的运动设置 `DURATION_CAPPED` 标记；保留峰值和子触发计数，不无限保留波形。
- D2 SRAM1 专用于非缓存 DMA；事件块放在 AXI SRAM。

## 数据所有权

样本块是唯一的数据副本。引用只表达谁仍需要该块，绝不复制块数据。

```text
FREE -> FILLING -> READY -> 被一个或多个消费者持有 -> FREE
```

- 采集线程只可写入 `FILLING` 块；发布后样本块不可修改。
- `ARMED` 状态下，预触发环持有最近 25 块。新块到来使窗口超过 25 块时，环释放最旧块的引用。
- 有效触发后，事件组装器取得这 25 块的事件引用，并继续持有后触发块。
- 导出器成功发送某块后释放该块的事件引用；超时、失败或清除事件时释放所有事件引用。
- 仅当引用数为零，块才可重新进入 `FREE`。任何资源不足都必须计数并明确标记，不能覆盖被引用块。

## 触发规则

- 只使用加速度；不在 Phase 05 使用陀螺仪规则或 AI。
- 使用合加速度平方值与阈值平方值比较，避免高频开平方和浮点差异。
- 连续 2 个样本达到阈值才产生有效触发。
- 阈值以原始整数配置；具体数值等待实物静止、轻敲和保护盒小跌落数据校准。
- 触发事实包含时间、样本序号、峰值平方值、阈值平方值和三轴方向掩码。

## 事件状态机

```text
ARMED
  -> POST_TRIGGER_CAPTURING
  -> READY_FOR_EXPORT
  -> EXPORTING
  -> ARMED
```

- `ARMED`：持续维护预触发环。
- `POST_TRIGGER_CAPTURING`：冻结触发前窗口，并接收后触发块；重复触发更新峰值、子触发数和结束时间，但不可超过 4 秒总窗口。
- `READY_FOR_EXPORT`：事件已完整，只允许导出或清除。
- `EXPORTING`：按时间顺序发送块；不得夹杂文本日志；导出期间新触发只增加忙碌计数。
- `event clear` 仅能清除 `READY_FOR_EXPORT` 事件；采集中或导出中必须拒绝。

## EV01 调试格式

EV01 是 MCU 到 PC 的临时二进制格式，不是长期存储格式，也不是第 08 阶段的 TERP 帧。

- 事件头固定 64 B，所有多字节字段为 little-endian。
- 头包含：`EV01` 魔数、格式版本、头长度、事件 ID、触发单调时间、采样率、触发样本序号、前后样本数、子触发数、标记、峰值、阈值、载荷长度和载荷 CRC32。
- 标记至少包含 `PRETRIGGER_SHORT` 和 `DURATION_CAPPED`。
- 载荷中每个样本固定 16 B：六个 `int16` 六轴值、`uint16` 时间戳、`int8` 温度和 `uint8` FIFO 头。
- 触发样本是后触发数据的第一个样本；其在载荷中的索引等于 `pre_sample_count`。
- MCU 必须逐字段编码，不能发送 C 结构体。
- PC 必须验证魔数、版本、头长度、样本长度关系和 CRC。失败时不得生成正常事件结果。

## 操作与故障处理

支持 `event status`、`event arm`、`event trigger_test`、`event export` 和 `event clear`。

- `trigger_test` 只注入触发事实，不伪造传感器样本。
- 导出使用 921600 波特率。导出一个块后释放该块的事件引用。
- 预触发不足时生成事件并置 `PRETRIGGER_SHORT`。
- 块池压力、导出超时、主机断开和状态非法跳转都必须计数；异常路径释放它拥有的引用并恢复到安全状态。

## 验收

1. 原生测试覆盖触发阈值边界、环回、引用释放、状态机、CRC 和损坏文件拒绝。
2. 板上连续 100 次 `trigger_test` 后，空闲块数恢复到初始值。
3. 静止、轻敲、保护盒小高度跌落各至少 10 次；PC 曲线出现稳定段、峰值和衰减段。
4. 每个导出的正常事件都含触发前和触发后数据；长事件和预触发不足均在元数据中明确标记。
